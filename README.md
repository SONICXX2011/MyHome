# MyHome — مربی رشد شخصی

Android / Java 17 / Material Components

## امکانات نسخه 1
- Splash Screen متحرک
- دریافت نام در اولین اجرا و امکان ویرایش
- داشبورد تیره و گرافیکی
- رکورد پاکی و بهترین رکورد
- ثبت تمرین، عبادت و گزارش روزانه
- XP و Level
- یادآوری روزانه ساعت ۲۰:۰۰
- بازسازی آلارم بعد از reboot یا update
- GitHub Actions برای ساخت APK

./gradlew assembleDebug
